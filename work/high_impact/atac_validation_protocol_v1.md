# 机械干预 ATAC-seq 外部验证：预设分析方案 v1

**冻结日期：2026-09-08。** 本方案在提取任何基因层 ATAC 结果之前冻结。数据来自 GSE287556；转录组刚度效应和基因集来自此前完成的 7 个独立研究元分析。

## 主要问题与分析单位

主要问题：衰老/衰老样人 BMSC 接受适量机械牵张后，启动子开放性是否沿既有“高刚度转录反应”的方向改变。

- 主要比较：`Force+`（5% strain，0.02 Hz，2 h；2 个样本）相对 `senescent`（2 个样本）。
- 独立单位为公开数据中的样本；细胞或基因均不作为生物学重复。
- 因每组仅 2 个样本，不进行逐基因显著性差异分析，也不宣称单基因因果关系。

## 注释与信号定义

- 使用明确记录版本的 GENCODE GRCh38 综合注释。
- 纳入常染色体和 X 染色体的 `protein_coding` gene feature；每个 gene feature 按链方向取一个 TSS。
- 主要区域为 TSS 上下游各 2 kb，限制在染色体边界内。
- 每个样本取该区域 BigWig 平均信号，变换为 `log1p(signal)` 后在样本内转为百分位秩，以降低不同 BigWig 全局尺度的影响。
- 组效应为两个 Force+ 样本平均秩减去两个 senescent 样本平均秩。

## 预先固定的主要检验

既有元分析按 pooled effect 排序固定 100 个正向和 100 个负向基因；不依据 ATAC 结果更换成员。

主要统计量：`D = mean(ATAC_delta_positive) - mean(ATAC_delta_negative)`。

方向性备择假设为 `D > 0`。用 20,000 次分层置换给出单侧 P 值。随机基因按衰老组基线开放性十分位及 gene length 十分位匹配；每次分别抽取与正、负基因集相同的数量。若匹配层不足，则在相邻基线十分位内扩展并记录。

主要检验只有一个，不与探索性检验合并校正。

## 预设的次要与敏感性分析

1. 全基因组 Spearman 相关：元分析 pooled effect 与 ATAC delta。
2. 分别比较正向、负向基因与匹配背景；次要检验统一 BH-FDR。
3. 单细胞研究作者定义的 5 个富集 marker 集合做竞争性检验；5 个 P 值 BH-FDR。
4. 使用原始 promoter mean 经各样本总信号缩放后的结果重复主要统计量。
5. 样本间 promoter 信号 Spearman 相关和非零覆盖比例作为 QC。
6. FOXO1 仅作已知阳性机制的描述性检查，不纳入主要检验。

## 双向验证（在主要分析完成后执行）

独立下载 young 与 Force−（软基质 1.5 kPa）样本。预设期望为年轻细胞的力学减弱效应与衰老细胞机械牵张效应方向相反。报告同一主要统计量及两组效应的一致/相反方向；不以其中任一结果修改主要假设。

## 判定规则

- 若主要检验方向正确且 `P < 0.05`，且两个组内样本的 promoter 全基因组相关均不低于 0.70，则视为支持表观遗传层外部验证。
- 若仅方向正确但未达显著，定义为趋势证据。
- 若方向相反或 QC 不足，定义为不支持；保留结果并相应降低论文主张。
- 双向验证需 Force+ 与 Force− 的统计量方向相反，才称为可逆性证据。

## 防止结果驱动分析

主要区域、基因集大小、统计量、置换次数、匹配变量、方向和判定阈值均在读取基因层 ATAC 结果前固定。任何后续改变只能列为探索性分析，并在方法和结果中明确标注。
